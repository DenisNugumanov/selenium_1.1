Тестирование веб-интерфейсов с Selenium

Выполнив это задание, вы научитесь:
 Писать автоматизированные тесты с использованием Selenium.
 Использовать библиотеку pytest для организации тестовых сценариев.
 Работать с веб-формами, находить элементы страницы и выполнять действия над ними.
 Проверять результаты выполнения теста с помощью assert.
 Находить и устранять ошибки в тестах.
 Интегрировать проект в CI/CD с помощью GitHub Actions.

Чек-лист готовности к практическому заданию
Перед началом убедитесь, что вы:
 Установили Python (версия 3.8+).
 Установили pytest и selenium через pip install.
 Ознакомились с базовыми понятиями работы с Selenium: поиск элементов, взаимодействие с ними, ожидания.
 Понимаете, как использовать фикстуры в pytest.
 Знаете, как работать с веб-формами и проверять результаты действий пользователя.

Описание задания
Вам нужно создать автоматизированные тесты авторизации с использованием Selenium и pytest для следующей формы:the-internet.herokuapp.com....com/login

Тестовые данные:
 Успешная авторизация: логин tomsmith, пароль SuperSecretPassword!
 Неуспешная авторизация: неверные логин или пароль.

Что нужно сделать:
Написать два теста:
a. test_successful_login — проверяет успешный вход.
b. test_unsuccessful_login — проверяет неудачную попытку входа.
def test_successful_login(driver):
   driver.get(https://the-internet.herokuapp.com/login)
    # заполняете через driver форму и кликаете на кнопку
    # находите элемент, по которому будете проводить ассерт успешной авторизации
    # пишете assert <выражение, которое должно быть True при успешном прохождении теста и False в других случаях>
 
2. Использовать фикстуру driver из условия задания для создания браузера.

@pytest.fixture

def driver():

#Selenium Manager will auto-download the appropriate driver
             options = Options()
             options.add_argument("--headless")  # run without UI
             options.add_argument("--no-sandbox")  # required in many CI environments
             options.add_argument("--disable-dev-shm-usage")  # overcome limited /dev/shm size on Linux
 
   driver = webdriver.Chrome(options=options)

   driver.quit()


Драйвер с такими настройками будет запускать браузер в невидимом режиме, что идеально подходит для будущего CI.
 
3. Внутри тестов не забудьте сделать assert, подтверждающий успешность или неуспешность авторизации.
4. Экспортировать зависимости в файл requirements.txt.
5. Загрузить проект в публичный репозиторий на GitHub.
6. Настроить CI с помощью GitHub Actions: тест должен запускаться автоматически и показывать статус “passed”.

Инструкция к выполнению
1. Создайте новый проект в PyCharm или любом другом редакторе кода.
2. Установите необходимые библиотеки: pip install pytest selenium
3. Добавьте в проект файл test_form.py.
4. Скопируйте и используйте предложенную фикстуру driver.
5.Реализуйте оба теста:
  a. В первом случае введите правильные логин и пароль, проверьте наличие сообщения об успешном входе.
  b. Во втором случае введите неверные данные, проверьте наличие сообщения об ошибке.
6. Убедитесь, что тесты проходят локально.
7. Зафиксируйте зависимости в PycCharm через Tools > Sync Python requirements.
8. Создайте публичный репозиторий на GitHub и загрузите туда свой проект.
9. Настройте GitHub Actions через интерфейс GitHub на вкладке Actions, который будет запускать тесты с помощью pytest.
10. Проверьте, что ветка содержит зелёную галочку в GitHub Actions (статус passed).
